# Repository instructions

This repository hosts the public privacy policy for jutsu.

- Keep changes limited to this public policy website.
- Do not add private application source, credentials, or internal documents.
- Keep index.html as a static, publicly readable HTML page.
- Preserve the accurate data-handling disclosures and owner-approved contact details.
- Verify that GitHub Pages serves the updated page after publishing.
- Use one writer at a time.
